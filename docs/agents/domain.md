# Domain docs

Read the root [glossary](../../GLOSSARY.md) before changing terminology, writing a spec, or planning a feature. Read relevant decisions under `docs/adr/` before changing an area they cover.

This repository uses a single domain context. Add a glossary term when its meaning is settled. Record a decision under `docs/adr/` when it is consequential, hard to reverse, and otherwise surprising to a future contributor.
