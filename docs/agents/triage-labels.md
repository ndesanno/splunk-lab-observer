# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| Needs evaluation | `needs-triage` | Maintainer needs to evaluate the issue |
| Needs more information | `needs-info` | Waiting for the reporter |
| Ready for an agent | `ready-for-agent` | Specified work an agent can pick up |
| Ready for a human | `ready-for-human` | Requires human implementation or decision |
| Will not act | `wontfix` | Work will not be actioned |

Use the label in the middle column whenever a skill names the corresponding role.
